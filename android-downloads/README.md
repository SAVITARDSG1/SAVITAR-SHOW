# ППЭС для Android

[Скачать APK](https://github.com/SAVITARDSG1/SAVITAR-SHOW/raw/refs/heads/main/android-downloads/ppes-0.1.0-debug.apk)

Тестовая версия 0.1.0 для Android 8.0 и выше, подписана debug-ключом. Новости, контакты, личный кабинет, показания и обращения.

Сборка и 5 модульных тестов пройдены; Android lint — без замечаний. На устройстве и действующем сервере приложение пока не проверялось.

API: https://ppesasup.temp.swtest.ru. В предоставленном архиве PHP был указан другой origin; проверьте, что настройка действующего сервера совпадает с этим HTTPS-адресом.

Контрольная сумма APK находится в SHA256SUMS.
